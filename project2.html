Project 2 - Data Analysis

Dashboard for anime data analysis

For my Data Analysis, I made a dashboard with data from MyAnimeList. Using the data analysis knowledge I have acquired this term, I sorted the data and visualized many different types and varieties of data. Throughout this task, I encountered some difficulties in sorting the data. One of them included the varieties of anime genres, making the original data display too many anime genres with little useful information. From this, I had to sort it with the data only displaying the most important information, solving this problem. Another problem I encountered was my data disappearing after I deleted my subdatasets. To solve this problem, I created a new sheet for my subdata so the data would stay. Throughout this term, I have learnt how to sort data and create a good dashboard from a dataset. I learnt how to sort the data, filter it, and through multiple challenges, created a dashboard with the most important graphs and data.
